# Patliputra VinFast website (flat version)

All files are in one folder level, so you can upload them to GitHub with "choose your files".
Upload everything you see here (index.html, all .jpg / .png / .webp images, vercel.json, package.json, robots.txt).

## AI chat (optional)
The chat works without this (ready-made answers + WhatsApp). For AI answers:
1. GitHub repo > Add file > Create new file. In the name box type: api/chat.js
2. Paste the code from the api/chat.js file in this zip, then Commit.
3. Vercel > Project Settings > Environment Variables > add ANTHROPIC_API_KEY, then redeploy.

## Keep in sync
Prices, offers, phone and address appear in index.html AND api/chat.js.

## After you have a domain
In index.html change og:image to the full URL, e.g. https://yourdomain.com/banner-vf-mpv7.jpg
